# Virlainn Hairstyle - Landing Page

A modern and elegant landing page developed for a beauty salon, focused on creating a sophisticated digital presence and improving customer engagement.

## About The Project

Virlainn Hairstyle is a responsive landing page designed to represent a beauty salon brand through a clean, sophisticated and user-friendly interface.

The project combines visual identity, responsive design and a clear call-to-action to provide a professional experience across different screen sizes.

## Features

- Responsive design for mobile, tablet and desktop
- Mobile-first development
- Elegant hero section
- Navigation between website sections
- Services presentation
- Image gallery
- About section
- Contact section
- Appointment call-to-action
- Smooth and modern visual effects

## Technologies

- HTML5
- CSS3

## Design

The interface was designed with a sophisticated beauty salon aesthetic, combining elegant typography, refined colors and high-quality imagery to create a premium visual experience.
